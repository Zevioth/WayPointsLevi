# Waypoint Manager

A native Levi Launcher waypoint manager for Minecraft Bedrock.

## What changed in 2.0.0

- One native Mod Menu module instead of the previous three-module staging flow.
- Mod Menu V2 categories and native controls.
- Custom waypoint names.
- Waypoint selector with searchable dropdown.
- Create, edit, save, hide/show, and delete actions.
- Coordinates entered directly as text fields.
- Overworld / Nether / End segmented selector.
- Persistent config and migration-friendly storage.
- HUD `WP` button opens the manager directly.
